\CLS{SL}Spatial dataflow neural processing units (NPUs) in client devices are small for the large language models (LLMs) they run, so a design either reconfigures the array between operators or fuses several operators into one configuration.
\CLS{SL}When an in-order command processor issues this work, as on the AMD XDNA\texttrademark{}~2 architecture, the compiled order is the array's schedule, and in fused designs it makes operations wait for work whose results they never use.
\CLS{SL}We present OPCORD, a post-compilation rescheduler that analyzes compiled XDNA~2 programs, both open- and closed-source, from multiple toolchains as dependence graphs, bounds the time recoverable by removing each such wait, rewrites issue order, dispatches, and buffers behind legality checkers, and selects the order and column groups for each prompt length with an event model.
