On client neural processing units (NPUs), a large language model (LLM) runs its operators on disjoint column groups of a spatial array, whose work one in-order command processor (CP) issues.
The CP's instruction order is therefore the array's schedule, and it is fixed in the instruction streams a toolchain emits.
In existing designs, that order makes column groups take turns although neither consumes the other's results, while a busy share computed from each operator's time alone reads the device as busy.
We recover the order from the streams of open and closed toolchains and identify each wait as a true dependence or a textbook false dependence on order or on storage.
From timings of each operator run alone, an event model and a lower bound then price a schedule, the split of columns between attention and matrix multiplications, and the removal of a wait.
OPCORD then reorders issue and renames the buffers of decode's loop behind legality checkers, with kernels, driver, and firmware unchanged.
Against the existing prefill with attention's two columns alternated by hand, each side on its faster split, OPCORD shortens the time to first token by $1.14$--$1.46\times$ from scratch and $1.20$--$1.51\times$ on appends to a cached context.
At a 16{,}384-token context, renaming shortens each decoded token of Llama-3.2-1B and Qwen3-4B by $1.27\times$ and $1.16\times$ against the unmodified decode design, and the two rewrites together shorten whole agent turns by $1.15$--$1.32\times$ against the existing program on its faster split, with bit-identical outputs.
The hardware provides concurrency that false dependences ration, in the CP's single in-order stream and inside an operator's loop.
